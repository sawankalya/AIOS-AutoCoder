# AIOS-AutoCoder

An AI-powered operating system layer that converts natural language commands
into real system actions using LLM-based agents and tool-calling.

## What this project does
- Understands user intent using LLMs  
- Plans multi-step actions  
- Executes system/terminal commands  
- Reads errors and attempts automatic fixes  
- Provides a simple interface for interacting with AI agents

Built on top of AIOS with custom extensions for autonomous debugging and execution.
